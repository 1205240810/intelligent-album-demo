# 智能相册分析系统

建议先打开 `01_直接演示/智能相册分析.html`。该文件不需要安装任何环境，双击即可查看全部 76 张照片、筛选器、分析结论和图表。

目录说明：

- `01_直接演示`：单文件离线演示。
- `02_项目源码`：前端、后端、数据生成脚本和完整文档。
- `03_项目文档`：项目说明书、测试报告、运行指南和 API 说明。
- `04_答辩材料`：组员完成的答辩 PPT。
- `文件清单与校验值.txt`：所有文件的 SHA-256 与大小。
