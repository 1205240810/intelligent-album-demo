## 答辩前口径核对

组员提供的 PPT 中出现了 Intel 图像数据集、PyTorch/CNN、PCA 和 t-SNE 等表述；当前压缩包内可验证实现是 76 张脱敏真实照片，以及基于 EXIF、GPS、文件时间和像素特征的启发式分析。答辩前请统一 PPT 与实际代码口径，避免把尚未在仓库中实现的训练流程描述为本版本功能。
