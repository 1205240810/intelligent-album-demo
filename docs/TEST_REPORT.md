本报告验证 2026-07-13 提交候选版本的数据完整性、前端逻辑、后端接口、生产构建、响应式视觉和离线交付。

## 3. 前端逻辑

- 支持数组、`photos`、`data` 和嵌套 `data.photos`。
- API 合法返回空数组时保持 0 张空状态。
- 非法枚举使用确定性兜底，非法分数回退到 `0.5`，越界值限制到 `0–1`。
- 重复 ID 自动生成稳定后缀。
- 筛选后 KPI、结论、四张图表和图片池同步变化。
- 无夏季样本时命中数、指标和图表归零，图片库显示“无匹配照片”。
- 图片库首批显示 24 张，每次继续加载 24 张，统计始终覆盖全部 76 张。

## 4. 后端接口

- 非 JSON 请求和目录穿越名称返回 `400`。
- 非法扩展名和伪图片被拒绝，临时文件不残留。
- 同名图片生成唯一文件名和独立 JPEG 缩略图。
- `/api/photos` 返回统一结构；空相册返回 `photos: []`。
- `/media` 只能读取 `users/` 内合法图片。
- 上传、删除照片、删除相册和删除用户后，三级统计保持一致。
- 用户统计缺失或物理照片数不一致时拒绝注销，防止平台统计漂移。
- JSON 使用临时文件、`fsync` 和原子替换写入。

## 5. 数据结果

- 记录数：76；图片数：76。
- 重复 ID、缺失图片、未引用图片：均为 0。
- 色彩和纹理分值全部位于 `0–1`。
- 公开 JPEG 未检测到 EXIF/GPS。
- 当前覆盖 8 个景点类型、2 个时段、3 个季节。

## 7. 离线与打包

- 自包含 HTML 含 76 张压缩图片、数据、CSS 和 JS。
- 使用 Edge 直接打开 `file://.../output/cos-single/index.html`，页面、真实图片、筛选器和首屏指标正常。
- 单文件生成器包含结构断言，防止 JS 拼接破坏 `script` 标签。
- PPT 缺失时 `npm run package:submission` 必须失败且不生成最终 ZIP。

## 8. 已知边界

- 后端没有账号鉴权，不应直接暴露为生产服务。
- 百度地图 AK 未配置时跳过 GPS 地址反查。
- 类别来自规则推断；本测试验证工程流程，不代表分类准确率评估。
- ECharts 异步分包约 557KB，首次进入页面会加载一次，但不阻塞首屏主包。
